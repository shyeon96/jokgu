## 우선 확인할 문제

회원가입과 경기장 등록은 요청 객체를 엔티티에 펼쳐 넣고 저장합니다. 그룹 승인, 일정 삭제, 경기 등록 등에는 사용자와 대상 리소스의 권한을 연결하는 검사가 빠져 있습니다. 인증된 사용자라는 사실만으로 해당 그룹이나 일정에 접근할 권한이 생기지는 않습니다. 구체적인 근거는 [C01, C02와 High 항목](findings.md)에 있습니다.

이전 분석 기록에는 지적 61건 중 59건이 반박되지 않았다고 적혀 있습니다. 중복, 영역 간 겹침, 내용 없는 placeholder가 포함된 집계이므로 고유 결함 수로 쓰지 않습니다. 이 문서는 당시 통합 표 45개 항목(Critical 2, High 5, Medium 17, Low 21)을 복원했습니다. 이 표에도 같은 문제의 프론트와 서버 원인을 나눈 항목이 있습니다.

## 근거와 상태

이전 세션은 영역별 분석 뒤 별도 검증자가 반박하는 방식으로 진행했습니다. 이번 문서화에서는 저장된 도구 입력과 결과를 복원하고 현재 HEAD 및 주요 소스, 호출부, 엔티티, 설정을 대조했습니다. 두 시점의 소스 기준은 같습니다.

서버, DB, 브라우저 시나리오와 애플리케이션 테스트는 실행하지 않았습니다. 소스에서 확인한 결함, 환경에 따른 조건부 위험, 요구사항 확인이 필요한 개선을 구분했습니다. 이전 초안의 “모든 화면에서 발생”, “취약점 없음”, “테스트 실패” 같은 단정은 확인 가능한 범위로 좁혔습니다.

기존 [Claude Docs 초안](https://claude.ai/code/artifact/e74703f3-420c-430b-a0e7-4579b1bff7fd)은 별도 문서입니다. 현재 연결 도구로 원격 본문을 읽거나 수정하지 않았으며, 복원은 로컬 세션 기록에 근거합니다.
